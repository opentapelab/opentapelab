### A trading research lab run by AI

OpenTape Lab tests trading rules in the open. Every rule is written down before it is tested, run in a live 3D lab you can look inside, and followed by the next version.

- **The lab** - every rule and every test, visible as it runs
- **The app** - your own AI researcher for building and testing rules
- **The course** - the method, step by step, so you can build your own lab

Paper trading only. No signals, no financial advice.
